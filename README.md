# 🎭 Quantise AI Simulator (MVP)

Интерактивный ИИ-тренажер жестких бизнес-переговоров для отработки коммуникативных навыков по методологиям SPIN-продаж и Гарвардского переговорного метода. 

Проект построен на связке высокопроизводительного асинхронного бэкенда **FastAPI**, реляционной СУБД **PostgreSQL** для хранения аналитики и локальной языковой модели **Ollama (Qwen2.5:3b)** для динамической генерации реплик клиентов.

РАБОЧИЙ САЙТ: https://quantise-hackathon.onrender.com/
(нет геймплея в связи с недостатком ОЗУ)

## 🚀 Пошаговое руководство по локальному запуску

### 1. Подготовка окружения и СУБД
1. Убедитесь, что на вашем компьютере установлена **СУБД PostgreSQL** и запущен сервер базы данных.
2. Через утилиту **pgAdmin 4** (или любой другой SQL-клиент) создайте пустую базу данных с именем `postgres` (или любым другим удобным для вас названием).

### 2. Настройка переменных окружения
В корневой директории проекта создайте файл **`.env`** и пропишите в него ваши доступы к локальной базе данных:
```env
DB_USER=postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432
DB_NAME=postgres
```
*(Файл `.env` намертво заблокирован в `.gitignore` и никогда не попадет в публичный репозиторий ради безопасности ваших данных).*

### 3. Развертывание локальной ИИ-модели (Ollama)
1. Скачайте и установите утилиту **Ollama** с официального сайта.
2. Откройте терминал Windows (PowerShell / CMD) и скачайте базовую модель Qwen командой:
   ```bash
   ollama run qwen2.5:3b
   ```
3. После завершения скачивания модель автоматически запустится в консоли. Для выхода из интерактивного чата нажмите `Ctrl + D`. Утилита останется работать в фоновом режиме на порту `11434`.

### 4. Установка зависимостей бэкенда
Откройте терминал в PyCharm (убедитесь, что вы находитесь в корне проекта) и выполните установку пакетов:
```bash
pip install -r requirements.txt
```
*(В список входят: fastapi, uvicorn, sqlalchemy, pg8000, pydantic, requests, python-dotenv).*

### 5. Запуск игрового сервера
Запустите сервер Uvicorn из корневой директории проекта следующей командой:
```bash
python -m uvicorn backend.main:app --reload
```
При старте FastAPI автоматически проверит PostgreSQL и самостоятельно создаст все необходимые таблицы (`users`, `sessions`, `messages`) с новыми аналитическими колонками под радарные графики.

### 6. Доступ к симулятору в браузере
После успешного запуска сервера откройте браузер и перейдите по адресу:
👉 **`http://127.0.0.1:8000`** (вас встретит главная страница).

## Способ установки №2: Запуск через Docker (GitHub Packages / Локально)

Вы можете запустить готовую сборку приложения из нашего реестра контейнеров GitHub Packages или собрать её локально.

### Вариант А: Запуск готового образа из GHCR
```bash
# 1. Авторизация в GitHub Packages (используйте ваш личный токен доступа PAT)
echo "YOUR_GITHUB_TOKEN" | docker login ghcr.io -u YOUR_GITHUB_USERNAME --password-stdin

# 2. Скачивание и запуск контейнера с прокидыванием переменных окружения
docker run -d \
  -p 8000:8000 \
  --name quantise-app \
  -e DB_USER="postgres" \
  -e DB_PASSWORD="your_password" \
  -e DB_HOST="host.docker.internal" \
  -e DB_PORT="5432" \
  -e DB_NAME="postgres" \
  ghcr.io/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME/quantise:latest
```

### Вариант Б: Локальная сборка контейнера
```bash
# Сборка образа из корня проекта
docker build -t quantise-local .

# Запуск локального контейнера
docker run -d -p 8000:8000 --name quantise-instance quantise-local
```

## 🔒 Безопасность и Режим гостя (UX фича)
Симулятор спроектирован по принципу *Privacy by Design*. Если пользователь запускает игру без авторизации, система активирует **Режим гостя**. Локальный ИИ будет полноценно вести диалог на все 10 шагов и пересчитывать шкалы в оперативной памяти, но бэкенд **не запишет ни одного лога в базу данных**, гарантируя полную анонимность.

*Примечание: Позже, после финальной полировки фронтенда и радар-диаграмм, в данный репозиторий будет добавлен `Dockerfile` для бесшовного контейнеризированного запуска всего стека одной командой через `docker-compose`.*
